# Circuit Scanner

Programa de reconhecimento, revisão e simulação de circuitos eletrônicos fotografados. O aplicativo fica em `project/`.

## Executar no Windows

Na pasta `project`, instale as dependências e abra o programa:

```powershell
python -m venv venv
.\venv\Scripts\python.exe -m pip install -r requirements.txt
.\venv\Scripts\python.exe iniciar_scanner.py
```

Os modelos, referências de reconhecimento, dados ativos de aprendizado e circuitos já salvos foram preservados. A versão principal contém os arquivos usados pelo aplicativo, sem relatórios antigos, auditorias, testes ou cópias de desenvolvimento.
